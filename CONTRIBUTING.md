# Contributing

Issues and pull requests are welcome. [docs/development.md](docs/development.md) covers building and testing; `make check-all` runs everything CI does.

## Releases

- Changes collect under "Unreleased" in [CHANGELOG.md](CHANGELOG.md) as they land.
- A version is tagged when a batch is worth upgrading for, not for every change.
- Breaking changes are grouped into one release where they can be, not shipped one per release.
